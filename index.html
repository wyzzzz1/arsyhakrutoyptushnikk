Публикация

Этапы создания такого сайта

Делай по порядку — так проще не запутаться.

Определи тему сайта

Например: экология, кибербезопасность, HTML, спорт, учебный проект или личная страница.

Продумай структуру

Запиши разделы сайта: главная, о проекте, инструкция, примеры, контакты.

Создай файл index.html

Именно этот файл браузер открывает первым, когда пользователь заходит на сайт.

Напиши HTML-разметку

Добавь заголовки, абзацы, списки, ссылки, изображения и разделы страницы.

Оформи сайт через CSS

Настрой цвета, размеры текста, отступы, карточки, кнопки и адаптацию под телефон.

Проверь и опубликуй

Открой сайт в браузере, исправь ошибки и загрузи файл на GitHub Pages.

Минимальный пример HTML-кода

Этот пример показывает основу любой HTML-страницы.

index.html 
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Мой сайт</title>
</head>
<body>
  <header>
    <h1>Мой первый сайт</h1>
  </header>

  <main>
    <h2>О проекте</h2>
    <p>Это пример сайта, созданного на HTML.</p>
  </main>

  <footer>
    <p>2026 год</p>
  </footer>
</body>
</html>

Чек-лист перед публикацией

Отметь пункты перед загрузкой сайта на GitHub Pages.

Как опубликовать сайт на GitHub Pages

  1. Создай новый репозиторий на GitHub.
  2. Загрузи в него файл index.html.
  3. Открой вкладку Settings в репозитории.
  4. Перейди в раздел Pages.
  5. В пункте Source выбери Deploy from a branch.
  6. В пункте Branch выбери main и папку /root, затем сохрани.
  7. Через несколько минут GitHub выдаст ссылку на сайт.
